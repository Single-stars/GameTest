# Homeworld skin placeholder

Replace this file with these PNG assets when adding a new skin:

- `room.png`: 1086x1448
- `mirror.png`: 786x1179, visible content box `x=73 y=131 width=640 height=1040`
- `bed.png`: 764x762
- `door.png`: 613x1093
- `ladder.png`: 342x1268
- `cabinet.png`: 654x694

Skin images must keep the same canvas size and transparent padding as the matching default object. Do not change furniture layout, hitboxes, or scene coordinates for a skin.
