# 测测你的游戏段位

一个移动端优先的 Next.js 原型：8个小游戏测测你的段位。

## 当前内容

- 8 项指标：反应力、精准度、侦察力、专注力、节奏感、记忆力、控制力、耐心。
- 本地计分：所有操作事件只在浏览器内计算，不需要登录、后端或排行榜。
- 结果页：展示段位、八项评分、雷达图、分享图片和重新测试。
- 图片分享：点击分享按钮后自动复制分享链接，并在页面内展示图片，方便微信长按保存或转发。
- 微信卡片：页面元信息使用 `https://gametest.p8.ink/`，分享缩略图来自 `public/share-card.png`。
- 王者进阶：达到“最强王者”后解锁每项指标 10 个难度挑战；同一手机会保留当前结果和进阶进度。

## 王者进阶

达到“最强王者”后，结果页的八项指标详情旁会出现进阶入口。每个指标 10 个难度，完成一个新难度获得 1 颗星和 1 次运气抽取，8 项共 80⭐；运气最高 20⭐，总计 100⭐。

每个指标入口显示该指标最高成功进阶，范围为 `0-10`：未进阶显示 `0`，5 阶以上使用进阶色，10 阶使用金色完成态。结果页始终显示“运气”长卡；历史解锁进阶后可消耗抽取次数进入三滚轮抽奖，按 `0-100` 均匀抽分并换算为 `0-20⭐`，只保留历史最高，80 次内必满运气。重新测试会清空当前结果，但保留已完成的进阶挑战、运气星和抽取次数；若新结果不是“最强王者”，入口和进度仍保留，但不展示王者星级段位。

进阶王者段位按星数显示，例如 `绝世王者⭐45`：

```text
0-9    最强王者
10-19  至圣王者
20-29  无双王者
30-39  非凡王者
40-49  绝世王者
50-99  荣耀王者
100    传奇王者
```

## 当前约束

- 无账号系统。
- 无服务器写入。
- 无在线排行榜。
- 结果只代表本次浏览器操作表现，不做心理测评判断。
