# 测测你的游戏段位

一个移动端优先的 Next.js 原型：8个小游戏测测你的段位。

## 当前内容

- 8 项指标：反应力、精准度、侦察力、专注力、节奏感、记忆力、控制力、耐心。
- 本地计分：所有操作事件只在浏览器内计算，不需要登录、后端或排行榜。
- 结果页：展示段位、八项评分、雷达图、分享图片和重新测试。
- 图片分享：点击分享按钮后自动复制分享链接，并在页面内展示图片，方便微信长按保存或转发。
- 微信卡片：页面元信息使用 `https://gametest.p8.ink/`，分享缩略图来自 `public/share-card.png`。
- 王者进阶预留：已抽出星级段位映射，后续可接入每项指标 10 个难度、80 个挑战星和 20 个运气星。

## 开发命令

PowerShell 下优先使用 `npm.cmd`：

```bash
npm.cmd install
npm.cmd run dev
npm.cmd run test
npm.cmd run lint
npm.cmd run build
```

本地开发默认地址：

```text
http://localhost:3000
```

## 项目结构

```text
src/app/page.tsx          主页面、8 个小游戏、结果页、分享图片页
src/app/globals.css       全局样式和移动端布局
src/app/layout.tsx        页面元信息
public/share-card.png     微信分享卡片缩略图
src/lib/advanced-rank.ts  王者进阶星级段位预留逻辑
src/lib/scoring.ts        计分、段位、分享文案
src/lib/scoring.test.ts   计分与分享文案测试
```

## 后续进阶段位规划

达到“最强王者”后，可在结果页的八项指标详情旁增加进阶入口。每个指标 10 个难度，完成一个难度获得 1 颗星，8 项共 80⭐；后续再加入运气抽取 20⭐，总计 100⭐。

进阶王者段位按星数显示，例如 `绝世王者45⭐`：

```text
0-9    最强王者
10-19  至圣王者
20-29  无双王者
30-39  非凡王者
40-49  绝世王者
50-99  荣耀王者
100    传奇王者
```

## 当前约束

- 无账号系统。
- 无服务器写入。
- 无在线排行榜。
- 结果只代表本次浏览器操作表现，不做心理测评判断。
